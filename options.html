Preview as Markdown

Select Markdown text on any page, right-click, choose Preview as Markdown. A floating popup or sidebar shows the rendered HTML.

Convert HTML to Markdown

Select HTML, right-click, choose Convert HTML to Markdown. The popup shows the Markdown source.

Pull Request pages

On GitHub or Bitbucket PR pages, right-click anywhere and choose Preview PR as Markdown (raw). The real Markdown source of the description and comments is fetched and rendered. Private repos work when a token is saved in Settings.

Side Panel

Click the extension icon or press the toolbar button to open the side panel. Write Markdown or HTML, see live preview.

Tip: Set your default display mode (popup, side panel, or fullscreen overlay) in Settings. Your drafts autosave locally — download them as Markdown, styled HTML, or PDF from the editor status bar, or press Alt+Z for Zen mode.

About

MarkLens — Instant Markdown Renderer & Page Converter

How to use

Select text on any page → right-click → choose Preview as Markdown or Convert HTML to Markdown. The result shows in a floating popup, the side panel, or a fullscreen overlay on the page, depending on your default mode. On GitHub or Bitbucket pull-request pages, right-click anywhere → Preview PR as Markdown (raw). Press Esc to close the overlay.

Toolbar icon

Click the extension icon in the toolbar to open a quick menu. From there you can open the editor as a new tab, open the side panel, access settings, or view this page.

Side panel editor

Write or paste Markdown in the editor pane and see live rendered HTML on the right. Switch to HTML mode to paste HTML and get Markdown output. Use Split / Edit / Preview tabs to change the layout.

Popup controls

In the floating popup, use the toolbar to switch themes, change font family and size, copy the rendered HTML or Markdown source, and toggle between popup and sidebar display.

Tip: Press Esc to close the floating popup. Drag the bottom-right corner to resize it.
